# 📝 Reloj Analógico con CSS Transforms

## Nombre del Reto Seleccionado

**Reto JavaScript Básico (JS30, Proyecto 2): Implementación de un Reloj Analógico**

## Descripción Breve del Objetivo del Reto

Este proyecto implementa un **Reloj Analógico** completamente funcional utilizando HTML, CSS y JavaScript. El desafío se centra en calcular los grados exactos de rotación para las manecillas de las horas, minutos y segundos (`transform: rotate()`), asegurando que el movimiento sea suave y preciso. El objetivo es practicar la obtención de la hora actual en JavaScript y su correcta aplicación al estilo CSS en tiempo real.

## Tecnologías Utilizadas

| Categoría | Tecnología | Notas |
| :--- | :--- | :--- |
| **Estructura** | HTML5 | Base para la esfera del reloj y las manecillas. |
| **Estilos/Movimiento** | CSS3 | Estilización del diseño y uso de la propiedad `transform: rotate()` para las manecillas. |
| **Lógica** | JavaScript (ES6+) | Control de la función `Date()`, cálculo de los grados de rotación y actualización continua mediante `setInterval()`. |
| **Despliegue** | Render | Plataforma utilizada para el *hosting* estático del proyecto. |
| **Control de Versiones** | Git / GitHub | Utilizado para la gestión del código fuente. |

## Instrucciones para Instalar o Ejecutar Localmente

Para descargar y ejecutar este proyecto en tu entorno local, sigue los siguientes pasos:

1.  **Clonar el Repositorio:**
    Abre tu terminal o consola de Git y ejecuta el comando `git clone`:
    ```bash
    git clone [https://github.com/Estebin21/retojs.git](https://github.com/Estebin21/retojs.git)
    ```

2.  **Navegar a la Carpeta:**
    Accede al directorio del proyecto:
    ```bash
    cd retojs
    ```

3.  **Ejecutar:**
    Simplemente abre el archivo **`index.html`** directamente en tu navegador web preferido (Chrome, Firefox, etc.). El reloj comenzará a funcionar inmediatamente.
